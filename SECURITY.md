# Security Policy

## Supported versions

The latest tagged minor release receives security fixes. Older releases may be
asked to update before a report is reproduced.

## Reporting a vulnerability

Use GitHub’s private vulnerability reporting for `lennytools/lenny`. Do not open
a public issue containing an exploit, secret, private repository content or a
destructive proof of concept.

Include the Lenny version, host and operating system, the smallest reproducer,
the affected managed path and the security consequence. Lenny maintainers will
confirm receipt before asking for additional private material.

## Security boundary

Lenny is instructions and local support scripts, not a sandbox. It does not make
an underlying coding agent safe and it does not grant permission to deploy,
merge, spend money, access production or disclose repository contents to another
model vendor. Those actions remain governed by repository instructions and the
human operator.
