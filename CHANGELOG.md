## [0.1.0] - 2026-08-31

### Added

- Safe, idempotent Codex installation into existing repositories.
- Conversational `setup-lenny` workflow and persistent project profile.
- Lenny Doctor diagnostics.
- Default three-seat Software Implementation Council.
- Standard and high-stakes risk classes.
- Install, update, rollback, setup, doctor, risk and uninstall tests.
- GitHub Actions verification and release automation.
